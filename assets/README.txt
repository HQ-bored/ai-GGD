Put your sprite PNGs in this folder. Filenames the game looks for:

  ghost-green.png    your green-team ghost  (~48x48)
  ghost-purple.png   your purple-team ghost (~48x48)
  flame.png          spirit flame           (~32x32)
  jackolantern.png   jack-o'-lantern pickup (~40x40)

Anything missing is replaced by a generated placeholder shape, so the game
runs fine with this folder empty. Just drop files in with the same names —
no code changes needed.
